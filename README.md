# Maragatham S. — Developer Portfolio

Static portfolio built with HTML5, CSS3 and Vanilla JavaScript.

## Included
- Responsive developer portfolio
- Blue/off-white visual system based on the supplied reference
- Light/dark theme toggle
- Mobile navigation and active section highlighting
- Scroll reveal animations and back-to-top control
- - Certificate lightbox
- Resume view/download
- Mailto contact form

## Replaceable assets
- `assets/images/profile.jpg` — profile photo
- `assets/images/projects/` — project thumbnails
- `assets/images/certificates/` — certificate images
- `assets/resume/resume maragatham.pdf` — resume

## Deployment
This is a static site and can be deployed to GitHub Pages, Netlify, Vercel, or another static host. Keep the folder structure unchanged so relative paths continue to work.

## Important
Project GitHub/demo URLs and certificate credential URLs are intentionally left unfilled where no real URL was supplied. This avoids publishing invented links.
